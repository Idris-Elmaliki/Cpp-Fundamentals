# Cpp-Fundementals
A hub for my C++ work, whether it's data structures & algorithms, graphics programming, or even CMake.

Repositories
============

Data Structures & Algorithms (DSA)
----------------------------------

**Linear structures**
- [Linked-List](https://github.com/Idris-Elmaliki/Linked-List) — Singly linked list covering core node-based operations (insertion, deletion, traversal).
- [Stack](https://github.com/Idris-Elmaliki/Stack) — Basic stack implementation.
- [Queue](https://github.com/Idris-Elmaliki/Queue) — Queue implemented on top of a linked list.

**Trees & graphs**
- [Binary-Search-Tree-Cpp](https://github.com/Idris-Elmaliki/Binary-Search-Tree-Cpp) — Iterative, templated BST with `insert` and `contains`.
- [Recursive-BST-In-Cpp](https://github.com/Idris-Elmaliki/Recursive-BST-In-Cpp) — Recursive BST covering `insert`, `contains`, and `delete`, with a post-order DFS destructor.
- [Depth-First-Search-Cpp](https://github.com/Idris-Elmaliki/Depth-First-Search-Cpp) — All three DFS traversals (pre-order, in-order, post-order) on a BST.
- [Breath-First-Search-Cpp](https://github.com/Idris-Elmaliki/Breath-First-Search-Cpp) — BFS traversal on a BST using `std::queue`.
- [Heaps-in-Cpp](https://github.com/Idris-Elmaliki/Heaps-in-Cpp) — Heap implemented over `std::vector`, with insert/pop/sink-in operations.
- [Graphs-in-Cpp](https://github.com/Idris-Elmaliki/Graphs-in-Cpp) — Basic unweighted, bi-directional graph using an adjacency-set representation.

**Hashing**
- [Simple-HashTable---Cpp](https://github.com/Idris-Elmaliki/Simple-HashTable---Cpp) — Hash table built from scratch to study how `std::unordered_map` hashing and mapping work internally.\

**Sorting**
- [Basic-Sorts-Cpp](https://github.com/Idris-Elmaliki/Basic-Sorts-Cpp) — Bubble sort, selection sort, and insertion sort.
- [Merge-Sort-Cpp](https://github.com/Idris-Elmaliki/Merge-Sort-Cpp) — Merge sort (divide and conquer, O(n log n)).
- [Quick-Sort-Cpp](https://github.com/Idris-Elmaliki/Quick-Sort-Cpp) — QuickSort with a written comparison of its approach against merge sort and insertion sort.

**Projects**
- [Recreating-STL-containers](https://github.com/Idris-Elmaliki/Recreating-STL-containers) — Rebuilding `std::array`, `std::vector`, `std::list`, `std::deque`, and `std::unordered_map` from scratch, focused on manual memory management (no smart pointers) and deepening DSA fundamentals.

OpenGL
------
- [Triangle-In-OpenGL](https://github.com/Idris-Elmaliki/Triangle-In-OpenGL) — First dive into modern OpenGL: rendering a triangle using GLFW (windowing) and GLEW (modern GL support), heavily commented while learning the graphics pipeline.

CMake
-----
- [Learning_CMake](https://github.com/Idris-Elmaliki/Learning_CMake) — Step-by-step practice repo covering CMake basics: project setup, linking multiple executables, and linking libraries.
